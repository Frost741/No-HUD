# No HUD for Titanfall 1 (R1Delta)

**Removes the entire in-game HUD during matches.**

## ⚠️ Important
Please use this mod only in **Private Matches**, as it will not work on public servers.

## Installation

**No HUD for Titanfall 1 (R1Delta)**

Extract the mod files into your game's `addons` folder.

**HudToggle – Frontier Overhaul Patch**

Install this optional mini-patch only if you have **Frontier Overhaul** installed!

This patch replaces the `cl_player` file from Frontier Overhaul with a modified version that removes the damage direction indicator.

Supported Game Modes

The mod supports the following game modes:
- Attrition
- Campaign
- Capture Point
- Frontier Defense
- Titan Brawl
